Part A · The ideas
IDEA 1 · A TREE IS A GAME OF 20 QUESTIONS

How a decision tree decides

A decision tree asks yes/no questions about one feature at a time, like "is the flipper shorter than 206.5 mm?". Each answer sends the penguin down a branch until it reaches a leaf, which holds the prediction. Training means: find the questions (feature + threshold) that separate the species best.

Below is the real tree scikit-learn learns from your training data when you limit it to depth 2. Move the sliders to build a penguin and watch its path.

Try: flipper 215, culmen depth 15 → Gentoo. Now raise culmen depth above 17.65 and the tree says Chinstrap, even though a long-flippered Chinstrap is rare. A depth-2 tree is crude; the full tree adds more questions.

IDEA 2 · HOW IT PICKS A QUESTION

Gini impurity: how mixed is this group?

At each node the tree tries every feature and every threshold and keeps the split whose children are the purest. Purity is measured with Gini impurity (the default) or entropy:

gini = 1 − Σ (share of class k)²      0 = pure,   higher = more mixed

You see gini = … printed in every box of plot_tree. Now you know what it means.

Entropy (criterion="entropy", used in Exercise 1) measures the same thing with logarithms. It usually picks almost the same splits.

IDEA 3 · THE WEAKNESS

A tree with no limit memorises

Without max_depth, a tree keeps splitting until every leaf is pure. On training data that looks perfect. On new data it often isn't. You will see this in Exercise 2 on Melbourne house prices:

DecisionTreeRegressor (no limit)Mean absolute error
on training data$864
on test data$251,689

Almost zero error on data it has seen, a quarter million on data it hasn't. That gap is overfitting (high variance): small changes in the training data produce a very different tree. Lesson 1 had the opposite problem: linear regression underfit.

IDEA 4 · THE FIX

A random forest: many tree opinions, one vote

One deep tree is unreliable. Many deep trees that each make different mistakes, averaged together, are reliable. Two tricks make the trees different:

Bootstrap rows (bagging)

Each tree trains on a random sample of rows drawn with replacement. Some penguins appear twice, about a third not at all.

Random features per split

At every split a tree may only look at a random subset of features. max_features="sqrt" with 8 features → 2 or 3 candidates per split. This stops every tree from using culmen_length first.

Classification: the trees vote, majority wins. Regression: the predictions are averaged. On Melbourne, a forest drops test MAE from $251,689 to $190,415 and lifts R² from 0.55 to 0.72.

NOTEBOOK · "UNDERSTANDING THE METRICS" (cell 28)

Precision, recall, F1, support

Here you write the definitions yourself. Use the confusion matrix above and think about one species at a time, say Chinstrap:

Precision

Look down the Chinstrap column: of all penguins the model called Chinstrap, how many really were?

Recall

Look along the Chinstrap row: of all real Chinstraps, how many did the model find?

F1-score

One number that balances both (harmonic mean). It is low if either one is low.

Support

How many real penguins of that species are in the test set. Small support = less trustworthy score.

MAE

Average absolute miss, in dollars. Easiest to explain.

MSE

Average squared miss. Punishes big misses hard. Units are dollars², so take the root (RMSE) to read it.

R²

Share of the price variation the model explains. 1 = perfect, 0 = no better than always guessing the mean.
